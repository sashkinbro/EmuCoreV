# Native shell coverage

The target is indistinguishable appearance and behavior against the owned Vita
reference. This is an implementation inventory, not a claim of completion or an
exhaustive list of every behavior found in the original. Add newly identified
states here while reconstructing them. A screen being visible does not prove
its animations, timing, inputs or lifecycle are equivalent.

| Area | Required states and transitions | Current native state |
| --- | --- | --- |
| Cold start | Loading-circle animation; asynchronous resource readiness; lock screen; date/time; peel/unlock gesture and cancellation; transition to Home | BusyIndicator motion/start/stop reconstructed and checked against original functions; packaged lock wallpaper/date/clock, native page-turn renderer and touch fold are integrated in the preview. Startup/readiness controller, original lock composition and full shell transition remain pending. |
| Page turn/unlock | Original corner geometry, hit region, drag tracking, release/cancel decisions, folded surfaces, shadows and settling/return animations | Development preview integrates recovered fold geometry, mesh, shader set, touch tracking, release threshold, cancel-to-return and peel/return animation. Prior shader/geometry measurements cover selected records, not full scene parity. Camera/depth equivalence, complete material/pass ordering, shadow fidelity and shell transition remain unresolved. |
| Resume | Preserve current page, selection, LiveArea and animation state; no repeated cold-start sequence after game/background return | Window recreation retains bubble phase; Home focus survives opening/closing LiveArea in the active window. Full pause/resume, app/game lifecycle and state persistence are pending. |
| Home | Every visible element, labels, fonts, bubble geometry/materials, idle movement, focus glow, hints and page indicators | Development scene reads the packaged title-keyed catalog, displays the catalog games with generated labels, bubble renderers, recovered cone-motion basis, a focus-glow image and status sprites. Grid placement is provisional 3-4-3. Direct Home clears to black: original animated wave/skydome background and its lighting/material composition are missing. Bubble lighting/environment response is only the recovered bubble shader/resource path, not the shell's full Home lighting. The Home focus glow is a sprite; the original focus shader/environment input is not reconstructed (environment input remains zero in the relevant capture). Hints, original text/font rasterization, page indicators and exact transforms remain pending. |
| Paging | Touch drag, linked movement of all elements, inertia, page settling, reversals, edge/overscroll response, indicators and background effects | Horizontal swipe switches the displayed catalog page; DPAD left/right moves linear focus and selects the corresponding page. No interpolated scroll/linked layer movement, inertia, settle/reversal, overscroll, page indicators or wave-background motion is implemented. |
| Input | Touch and gamepad focus/navigation; confirm/back; directional repeat; button prompts; rear-panel behavior where applicable | Home accepts bubble taps, DPAD left/right and A/Enter to open LiveArea. LiveArea accepts Back/B to return with focus retained; A/Enter and declared target taps report preview intent strings only. No directional repeat model, hints/prompts, rear-panel behavior, or broad gamepad parity. |
| Sound | Original UI sound assets; correct per-event routing, gain, stereo/loop behavior and lifecycle; no playback while suspended | 44 ready WAV assets and original event bindings prepared in the ignored pack; runtime routing/playback pending |
| Editing | Hold on a bubble, entry/exit effects, selection, moving/reordering, deletion, folders and cancellation paths matching the reference | Pending |
| LiveArea | Opening transition from bubble; intermediate game page, background, controls, prompts and reverse transition | Home tap/A opens a title-keyed native composition from each packaged game's template/images: background, A3 frame artwork, rasterized template text, startup gate and `plane_div` 9-slice gate bevel (`0xca6a6db1`, bit-exact to `paf.elf` `PlaneObj` layout/vertices) are layered using the current A3 layout. Back/B returns to Home with selection retained. Only current fixture templates/style A3 and supported template fields are represented; layout provenance is the existing LiveArea implementation's A3 table, not a proven shell trace. Open/close transitions, focus glow (`0xd5dd35e7`), complete template semantics, exact font treatment, prompts and target-specific gate semantics remain pending. |
| Launch | Start action and complete launch animation; launch through the existing game path; real readiness/errors; no black frame treated as success | Native preview has no launch/core bridge: gate confirmation or target taps only store a preview intent string in the host. Real launch sequence, readiness/errors and handoff remain separate and pending. |
| Game running | Stop native UI callbacks, clocks, radio observers and GPU submissions; release appropriate GPU resources | Preview pauses rendering; complete game/host integration pending |
| Return/close | Reference return animation; correct Home/LiveArea destination, selected game and page; cancellation and repeated launches | Back/B closes the preview LiveArea and retains Home focus/page in the current native window; reference reverse animation, lifecycle return paths and repeated launch/return behavior are pending. |
| Status bar | Matching textures/layout/typography; real Android battery/charging, Wi-Fi, Bluetooth and local time; event-driven updates | Kotlin event source and C++ sprite composition visible on Lenovo/RG556; paired electric charging textures and original RNG ported; exact anchors, font rasterization, charging entry/exit opacity and timer-event ordering pending |
| Trophies | Original presentation with real trophy data, locks, progress, lists, details and navigation | Deferred until shell composition/host bridge |
| Library changes | Add/delete/update games; install/remove selected game; refresh icons/metadata; changes while UI is paused or a game is active | Existing emulated catalogue sync implemented; native host binding pending |
| Themes/settings | Original theme/wallpaper behavior; host settings tab; native UI-only resolution; game graphics remain separate | Pending |
| Locales | Every supported application language, including Ukrainian; main strings files; technical terms preserved as appropriate | Host text boundary defined; native screens pending |
| Display/device | Correct geometry on phone/tablet/handheld; corners/cutouts and safe spacing; no stretched UI; independent 60 FPS menu pacing | Aspect-preserving preview; short Lenovo 60 FPS sample; final adaptive layouts pending |
| Release/upgrade | No development preview, probes, loggers or dumpers in release; preserve installed games/settings/trophies during upgrades | Preview is opt-in/debug-only; prior 0.2.7→0.2.8 upgrade tested; new native integration pending |

Before replacing the emulated mode, compare complete sequences, including
interrupted/reversed gestures and failure/recovery paths. Current known shader
fidelity differences on Mali are recorded in README.md and remain unresolved.
